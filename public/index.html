放假前不公布保護機制

設定每場定期評量成績之開放時間。系統自動比對，避免於週五或假日前夕發布成績，維護學生假期身心健康。

教育部與教育局法規指引：「放假前一日不公布成績」

依《國民小學及國民中學學生成績評量準則》及各縣市學生評量指引，定期評量結果不得於連續假期、寒暑假或例假日前一日發送或線上開放，以防學生因成績波動而在缺乏學校師長支持之假期引發嚴重親職衝突或負向情緒。建議老師將開放時間預約於放假結束後之上課日（如週一上午 08:00）。

3 步驟完成 Google 試算表免費雲端串接：
  1. 在 Google 雲端硬碟新增一份 Google 試算表，第一列放欄位標題：座號, 姓名, 密碼, 國文, 英文, 數學, 自然, 社會。
  2. 點擊上方選單「擴充功能」 → 「Apps Script」，將下方代碼複製貼上並儲存。
  3. 點擊右上角「部署」 → 「新增部署作業」，類型選「網路應用程式」，存取權限選「任何人 (Anyone)」，將取得的網址貼回左側欄位即完成！
function doGet(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = sheet.getDataRange().getValues();
  var headers = data[0];
  var result = [];
  for (var i = 1; i < data.length; i++) {
    var row = data[i];
    var obj = {};
    for (var j = 0; j < headers.length; j++) {
      obj[headers[j]] = row[j];
    }
    result.push(obj);
  }
  return ContentService.createTextOutput(JSON.stringify(result))
    .setMimeType(ContentService.MimeType.JSON);
}
